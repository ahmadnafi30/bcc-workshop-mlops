# BCC Workshop — MLOps

Welcome to the workshop documentation.

The documentation will be developed around three questions for every concept and tool:

1. **What is it?**
2. **Why do we need it?**
3. **How does it work in this project?**

## Workshop Use Case

We will build an end-to-end **urban mobility / taxi demand forecasting** system and simulate incremental production data using historical replay.

## Learning Flow

Data → Airflow → DVC → Training → MLflow → FastAPI → Docker → CI/CD → Monitoring → Retraining

> The detailed chapters and hands-on instructions will be added progressively.
